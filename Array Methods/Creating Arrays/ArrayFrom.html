ARRAY from

String 'JS' ko Array.from() se characters ki array banao.

Array.from() se 1 se 5 tak ki array banao.

Set mein duplicates hain — Array.from() se unique values ki array banao.

Array.from() se 0 se 4 tak ke squares ki array banao.

Map object ko Array.from() se array of arrays mein convert karo.

Array.from() se ek alphabet array banao — 'a' se 'e' tak — charCodeAt use karo.
